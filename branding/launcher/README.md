# Final launcher artwork goes here

Supply approved brand PNGs before public production. See `docs/LAUNCHER_ICONS.md`.

Required filenames:

- `ic_launcher_foreground.png` (1080×1080)
- `ic_launcher_background.png` (1080×1080) — or solid color only
- `ic_launcher_full.png` (1024×1024)
- `ic_launcher_round.png` (1024×1024) — optional
- `ic_launcher_monochrome.png` (1080×1080) — Android 13+ themed icon

Do not commit third-party or Flutter default logos as final brand assets.
